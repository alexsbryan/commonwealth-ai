Use this tool for questions that depend on information that changes over time — current events, breaking news, recent prices or scores, today's weather, who currently holds a position, the latest release of a product. Skip this tool for questions about stable knowledge: definitions, historical events, mathematical or scientific facts that don't change, or things stated earlier in this conversation that you can recall directly. When you use information from a search result, cite the URL of that result inline next to the claim it supports — copy the URL verbatim from the result rather than rephrasing it.
