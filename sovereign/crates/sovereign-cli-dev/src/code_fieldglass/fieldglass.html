Start here — the largest evidence first

Nothing below is a verdict: each list is evidence sorted by magnitude (redundant lines, caller split, file size), biggest first. Click a row to light it up on the field; click again to clear.

The field — every .rs file, area = lines

Crate boxes sit in fixed (layer, name) order; files in path order — positions are stable across renders, so change reads as change. The default view is deliberately calm — a quiet field is the baseline that lets pathology pop. Add one lens at a time: red-ringed 1200-line offenders are always on; toggle duplication arcs (copy instead of reuse), SRP communities (a bridge file's callers split across co-change communities), ghost edges (change together, no structural edge), fan-in heat.

Layer flow — declared bands, observed dependencies (DIP)

Bands are quality/ARCH_LAYERS.toml bottom→top; node size = incoming references, node color = instability (blue stable → orange volatile). Healthy: laminar downward flow. Diseased: red upward arrows against the grain, forbidden edges, dashed amber re-export-hidden coupling no Cargo.toml admits to. Hover an edge for the symbols that carry it.

Trait matrices — one interface, or two stapled together? (ISP)

Rows = consuming crates, columns = trait methods, both seriated so co-used groups sit together. Healthy: a dense matrix — everyone uses most of it. Diseased: block-diagonal — the blocks are the sub-traits waiting to be split. dyn counts references to the abstraction itself.
