Start here — the single biggest item of each evidence class

One row per class, biggest first — click to light it up on the field below; click again to clear. Nothing is a verdict. all evidence expands the full per-class lists.

    The field — every .rs file, area = lines. This is the one view.

    Crate boxes sit in fixed (layer, name) order; files in path order — positions are stable across renders, so change reads as change. The default paints only the strongest evidence: any layer violation as a red arrow between crates, the largest clone families, the strongest ghost couplings, ▦ marks on files defining a matrixed trait, red-ringed 1200-line offenders. Everything else waits behind a lens. Click evidence to drill through: an arrow opens the layer flow, a ▦ opens that trait's matrix, a matrix cell scopes the field to its call sites.

    [close] Layer flow — declared bands, observed dependencies (DIP)

    Bands are quality/ARCH_LAYERS.toml bottom→top; node size = incoming references, node color = instability (blue stable → orange volatile). Healthy: laminar downward flow. Diseased: red upward arrows against the grain, forbidden edges, dashed amber re-export-hidden coupling no Cargo.toml admits to. Hover an edge for the symbols that carry it.

    [close] Trait matrices — one interface, or two stapled together? (ISP)

    Rows = consuming crates, columns = trait methods, both seriated so co-used groups sit together. Healthy: a dense matrix — everyone uses most of it. Diseased: block-diagonal — the blocks are the sub-traits waiting to be split. dyn counts references to the abstraction itself.
