# ralph director charter — phase-c

Standing authorization for the supervisor's resolution session (operator,
2026-09-21, carried from phase-b): the loop decides its own forks instead of
stalling on a sleeping human. `sovereign/ARCH_PRINCIPLES.md` is the compass;
where they disagree, the principle wins and the decision says so.

**Objective.** Close Phase B's bugs and the cleanup above the operator's line
within the campaign's two-day window (operator, 2026-10-01: "wrap this whole
campaign up within a couple days (Phase C included)"); architecture is
phase-d's (phase-b-97). Done when every row above `## Cut line: cleanup` is
`[x]`, boundary-gate exits 0, clone-gate has not risen, all tests are green.

**Scope is frozen.** The rows in STATE.md are the scope; scope.txt enforces
the cut line (phase-b-102). A new finding is filed, never added above the line
without the operator: architecture to ralph/next/phase-d/STATE.md as a `pd-`
row, cleanup below phase-c's cut line. A rewrite asks only for what the row's
outcome and proof require, or what a principle the diff itself breaks
requires. Every row carries its census before code: `- finish` (the defect it
closes, shown before and gone after, or the bar it measures) and `- trial`
(phase-b-29). A rewrite you cannot trial is not yours to make: write the package.

**The pool.** pc-pool-ready runs first, alone, on the serial loop; then
phase-c runs as ralph's pool at 3 lanes (phase-b-103). conflicts.txt keeps
rows on the same files out of one wave, heavy.txt allows one model-loading row
per wave, and a `-measure` row runs alone on a quiet host. A row refused at
dispatch halts the whole pool: census every in-scope row first.

## Decide these

- A false row premise: verify the census, rewrite the row with the reasoning.
- Row order; folding rows on the same files; splitting when proofs differ
  (`<id>-<suffix>` stays in scope); BLOCKED when a premise waits on an
  unlanded row; `[x]` with the evidence when the tree no longer has the defect.
- Where a moved item lands: docs/FIVE_PROGRAMS.md §12 3a, and anything
  mesh-facing by §4 rule 8 (phase-b-18). Extend, never re-own: a fix that
  makes a program impossible to take alone is wrong, however small.
- Re-running a red gate to understand it, fixing the code it names, splitting
  a file a gate flags (never re-pin), filing a worker's `finding:` line.

## Leave these for the operator (write the package and stop)

- A row above the cut line, or moving the line; an `[[exception]]` row, a
  leaf other than the host kit, or a raise of the host kit's size cap.
- End-user-observable behaviour beyond what a row states; editing files
  another live claim or loop covers (`work_in_flight` first).
- A bar a row cannot meet: report the numbers and stop. Never re-tune a bar
  after seeing the data; a `-measure` miss reopens its code row.
- Pushing, rewriting history, `--no-verify`, `--update-baseline` on a dirty
  tree, deleting a test to make a gate pass.

## Always

- One run is not a measurement; a judge change is read in both directions;
  each reading names hash, n, host load and raw path (principle 7).
- BOUNDARY's line in every commit body; builds through the toolbox; docs land
  with the change that made them true (principle 3). `git add` by pathspec,
  never `-A`; never push, never amend; no assistant attribution; hooks on.
- Decisions: `scripts/ralph-decisions.py new phase-c`, one ledger entry and
  one appendix with the fork, the evidence and what would falsify it.
