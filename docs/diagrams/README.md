# Hand-drawn architecture diagrams

The flip-book. Eight figures that walk through "what is this?"
to "I see how the pieces fit" — the same story [`ARCHITECTURE_TOUR.md`](../ARCHITECTURE_TOUR.md)
tells in prose, drawn so you can *see* it. They render natively on GitHub (plain
`.svg`, no external assets), and each carries its own paper background so it reads
the same on a light or dark page.

## They are drawn from data, not by hand

The excalidraw look — wobbly strokes, hachure fills, one print-hand font — is
generated by [rough.js](https://roughjs.com/) from a tiny scene kit, so the whole
set shares one visual vocabulary and any global change (a palette tweak, a new
diagram) is a one-line edit and a re-render, not a redraw. Source is in
[`src/`](./src/): `kit.mjs` is the primitive library (boxes, arrows, cylinders,
the gate stamp), `build.mjs` is the eight scenes as data.

```sh
cd docs/diagrams/src
npm install
npm run build          # writes the .svg files back into docs/diagrams/
```

The colour legend is consistent across every figure: **blue** = surfaces / you,
**amber** = Sovereign (the assistant), **green** = cmnwlth (the mesh),
**purple** = corpus-engine (knowledge), **slate** = OICP (the base). A green
check is *released / verified*; amber is *rewrite*; red is *refused / abstain*.

## Font

The labels use [Patrick Hand](https://fonts.google.com/specimen/Patrick+Hand)
(subset to the glyphs used, ~13 KB woff2, embedded in each SVG so it renders the
same for every viewer). Patrick Hand is licensed under the SIL Open Font License;
the license text is in [`src/OFL-PatrickHand.txt`](./src/OFL-PatrickHand.txt).
