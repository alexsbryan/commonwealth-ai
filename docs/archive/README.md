# Archive

Point-in-time documents, kept because they are evidence of what was true on a
date, and moved here because a reader browsing `docs/` should not mistake them
for current.

The rule for landing here: the document describes a state rather than a
mechanism, its own text names the date or branch it was true for, and nothing
in the tree cites it. A doc that code, CI, or a script cites is not stale —
it is load-bearing and stays where the citation points.
