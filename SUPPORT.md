# Getting help

Stuck, confused, or just want to check something's working the way it should?
Here's where to go — picking the right spot means you get an answer faster, and
it's there for the next person who wonders the same thing.

## "How do I…" or "is it supposed to do this?"

Start a **[Q&A discussion](https://github.com/alexsbryan/commonwealth-ai/discussions/new?category=q-a)**.
Questions about setup, usage, or expected behaviour live there rather than in the
issue tracker. Anyone can answer — often it won't be us — and answered questions
become the map for everyone who arrives after you. Before you post, a quick
search of [past discussions](https://github.com/alexsbryan/commonwealth-ai/discussions)
sometimes saves you the wait.

A few things that help you get unstuck sooner:

- Your version — `svrn --version`, or the release tag.
- Your machine — hardware and OS (`svrn doctor` sums this up if the daemon's
  involved).
- What you tried and what happened, rather than only what you hoped for.

## "I think this is broken"

If something genuinely misbehaves — a crash, a wrong answer where it should've
known better, a command that does the wrong thing — that's a bug. Open an
**[issue with the bug template](https://github.com/alexsbryan/commonwealth-ai/issues/new?template=bug_report.yml)**.
It asks for your version and platform up front because that's usually the first
thing we'd need to ask you anyway.

Not sure whether it's a bug or just you holding it wrong? That's fine — start in
Q&A, and if it turns out to be a real bug, we'll move it over.

## "It could be better if…"

Ideas and feature requests start as an
**[Ideas discussion](https://github.com/alexsbryan/commonwealth-ai/discussions/new?category=ideas)**,
where others can weigh in and upvote. The ones that resonate get promoted to
issues and built. Describe what you're trying to *do* — the goal behind the
feature — not only the fix you have in mind; it often opens up a better answer.

Worth a read before you ask for something big: [what this project is *not*
trying to be](./docs/NON-GOALS.md). If your idea runs against one of those
lines, it's not that it's a bad idea — it's just not this project.

## Security or privacy

If you've found a vulnerability — including any way data could leave a machine
when it shouldn't — **please don't post it publicly.** Report it privately
through a [security advisory](https://github.com/alexsbryan/commonwealth-ai/security/advisories/new),
and see [SECURITY.md](./SECURITY.md).

## What to expect from us

This is a small team, so honesty up front: issues get triaged in batches, about
once a week, not the minute they land. If yours sits for a few days without a
reply, it hasn't been ignored — it's waiting for the next pass. A well-filled-in
report moves through that pass a lot faster than a one-liner.
