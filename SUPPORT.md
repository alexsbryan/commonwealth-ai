# Getting help

Pick the right door and you get an answer faster:

- **A question, or "is it meant to do this?"** → [Q&A discussion](https://github.com/alexsbryan/commonwealth-ai/discussions/new?category=q-a). Anyone can answer, and it's there for the next person.
- **Something's broken** — a crash, a wrong answer, a command misbehaving → [file a bug](https://github.com/alexsbryan/commonwealth-ai/issues/new?template=bug_report.yml). Not sure it's a bug? Start in Q&A; we'll move it if it is.
- **An idea** → [Ideas discussion](https://github.com/alexsbryan/commonwealth-ai/discussions/new?category=ideas), where people can upvote. First, a skim of [what this isn't trying to be](./docs/NON-GOALS.md) saves us both a long thread.
- **Security or privacy** — including any way data could leave a machine → **don't post it publicly.** [Report privately](https://github.com/alexsbryan/commonwealth-ai/security/advisories/new); see [SECURITY.md](./SECURITY.md).

Two things that get a bug fixed sooner: your version (`svrn --version`) and your machine (hardware + OS).

Small team, so honest heads-up: issues are triaged in weekly batches. A few quiet days means "waiting for the next pass," not "ignored."
