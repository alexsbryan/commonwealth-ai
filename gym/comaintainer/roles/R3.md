# R3 — measure progress

No model. This role is code, and it is a card only so the role list
stays honest about what is already built.

Progress against a campaign is coverage of its DECLARED bars: which
bars have a measurement, which do not, and how old each measurement
is. `scripts/co-lineage.py coverage <campaign>` computes it from
`quality/campaigns/*.toml` and `bar-measurements.jsonl`.

## What it must never do

Never estimate a bar nobody measured. An uncovered bar is reported
uncovered — that is the answer, not a gap to fill. A coverage number
that quietly counts an unmeasured bar as met is the failure this role
exists to prevent (ARCH §18.2: four verdicts, and `never-ran` is one
of them).

Never recompute a threshold. The bar's own line is the decider; this
role reads verdicts, it does not re-derive them (§10.6).

## Refusal condition

The campaign id does not resolve, or the coverage command exits
non-zero. Report `could-not-judge` naming the exit code and the
campaign. An empty coverage table for a real campaign is a RESULT
(nothing measured yet), not a refusal.
