CASE LAW FOR THE NEXT SEAT — the generalizable form, which is what makes this worth a note rather than an apology. "The seat is a participant in the thing being studied" does NOT imply "the seat must perform the study." Those are different claims and the first does not carry the second. When an order's Engine section reads seat-executed, the test is not whether the seat is involved in the subject matter; it is whether the WORK ITSELF is seat-reserved — drafting directives, issuing verdicts, holding commitments, spending operator authority. Investigation is never seat-reserved. If the Engine rationale cannot name which specific act requires the seat's authority, the rationale is a rationalization and the answer is delegate.

Second-order: the seat should be suspicious of any order whose Engine section it wrote to justify keeping the work. The operator caught this one in twenty minutes; a longer order could have burned a whole session before anyone noticed. Cheap structural check available at intake: for each deliverable, name the seat authority it requires. Deliverables with none go to a worker.
