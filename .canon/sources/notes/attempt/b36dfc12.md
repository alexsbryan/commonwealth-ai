# FOUR NEXT-EDIT RULE-LANE CANDIDATES REFUTED ON THE GOLDEN SET (2026-08-06, baseline d75a9c4c: useful-fire 41.4%, wrong-fire 53/347 =…

FOUR NEXT-EDIT RULE-LANE CANDIDATES REFUTED ON THE GOLDEN SET (2026-08-06, baseline d75a9c4c: useful-fire 41.4%, wrong-fire 53/347 = 15.3%). All four were killed by simulation against BOTH the 711 positives and the 387 negatives; no Rust was written. Do not re-try these without new evidence.

1. BLANKET support=1 FIRING — refuted. 89 negatives are silent ONLY because of the support>=2 threshold (they already have remaining sites), so dropping it fires every one of them as a wrong edit. Rule-find LENGTH does not separate the populations: swept minlen 2..100, neg-per-pos stayed 0.33-0.95 the whole way, and the only tolerable ratios (minlen>=50) leave 6 positives, under 1pt of useful-fire.

2. VARYING-PAYLOAD INSERTION (relax induce_insertion's `a.after == b.after` to "share a line-prefix, take one observed payload") — refuted. Most-recent-payload: +3 useful for +9 wrong (wrong-fire 15.3% -> 17.3%). First-payload: +5 for +7 (-> 16.7%). Both lose. This measures the claim already asserted in induce_insertion's doc comment ("guessing which variant belongs at an unseen site is exactly the inference this lane refuses to do") — it is now a number, not a taste.

3. support=1 WITH A SPECIFICITY/FAN-OUT TIER — refuted on a 20-cell grid (max_sites x {1,2,3,5,inf} x min_chars {2,6,10,16}) plus a split by induced-rule form (del/ins/sub). Best cell is max_sites=2, min_chars=16 at +4 useful / +1 wrong, wrong-fire flat. Not worth re-introducing the support tier that 833ea5c1 deliberately DELETED ("the support tier is gone, and that is a result"). Rule-form split: del +1/0, ins bad, sub +8/+8.

4. MIN_ANCHOR_CHARS 3 -> 2 — looks like a clean +5 useful / 0 wrong / 0 negatives, and IS NOT ONE. All 5 moves are missed->partial, zero become useful, and the anchors are `))` and `', ` firing at 25, 32 and 80 sites. It buys five large fan-outs that score partial because a few of the 80 proposals happen to be right. At min_anchor=1 it degrades outright (+3 wrong). See the companion note on over-offer magnitude for why partial flatters here.

5. LOCALITY (cap sites by distance from cursor) — refuted, and INVERTED. Truth edits for WRONG fires sit CLOSER to the cursor (median 913 u16) than for USEFUL ones (median 2188, p90 20167). A distance cap cuts good fires before bad ones.

METHOD NOTE, and the reason these were cheap: both simulators were validated before use. The insertion port fires on 0 rule-lane-silent cases under shipped parameters (it must — anything it fired on would not be silent), and the expand_rule port reproduces 824/830 shipped rules exactly (99.3%). A port that cannot reproduce the shipped rule is not evidence about anything.
