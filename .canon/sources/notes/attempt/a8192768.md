sovereign-test.sh exit 5 ("unattributable results") on 2026-08-07 in the skunkworks worktree was NOT the documented cause (a) alone. Two distinct faults stacked: (1) a peer worktree (~/dev/commonwealth-ai-recipe-gate) was running `cargo nextest run` concurrently on the same box — visible via `ps aux | grep cargo`, which is the first thing to check on exit 5; (2) nine artifacts under target/debug/deps were TRUNCATED (mode 644, type "data", e.g. a 3840-byte `knowledge_view_e2e-*`), so nextest's list phase died with "[double-spawn] failed to exec ... Permission denied (os error 13)" and `error: creating test list failed` — which the wrapper reports as exit 5, not as a build failure. Repair: `find target/debug/deps -type f ! -name '*.rlib' ! -name '*.rmeta' ! -name '*.d' ! -name '*.o' ! -perm -u+x` then delete the SMALL ones only. CAUTION learned the hard way: that filter also matches legitimate static archives (libpdfium_render-*.a ~71MB, libllguidance-*.a ~35MB) which are correctly non-executable — deleting them costs a long relink. Add `! -name '*.a'` or gate on size (`-size -1k`).
