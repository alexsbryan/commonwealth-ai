`mlx_lm fuse` CORRUPTS Qwen3.5 HYBRID MODELS TWO WAYS — DO NOT USE IT FOR VERIFIER_V0 ARTIFACTS (found 2026-07-29, M0 GGUF rehearsal; remedy shipped as research/verifier-v0/scripts/fuse_lora_manual.py).

DEFECT 1 — MTP layer silently dropped. Qwen3.5-0.8B's HF snapshot carries mtp.* tensors (multi-token-prediction). llama.cpp's qwen35 arch maps them to blk.24.nextn.* and stamps block_count = num_hidden_layers + 1 = 25. mlx-lm models only the 24 decoder layers, so the fused export has 320 tensors vs the snapshot's text-side 335 → converted GGUF fails at load: "missing tensor 'blk.24.attn_norm.weight'". The converter does NOT warn: it happily writes a GGUF whose metadata promises a block it never wrote.

DEFECT 2 — the merge itself is wrong for the hybrid stack. With MTP grafted back, the fused model emits token salad IN MLX ITSELF (not a conversion artifact): base+adapter unfused generates correctly, fused generates garbage. Qwen3.5 interleaves linear_attn (gated deltanet: in_proj_qkv/in_proj_a/in_proj_b/in_proj_z/out_proj) with self_attn layers; adapter covers 186 modules across both. Corruption isolated to the fuse step by three-way experiment (fused-in-MLX garbage / base+adapter coherent / base coherent).

THE REMEDY. fuse_lora_manual.py: copy the ORIGINAL HF snapshot wholesale (all 488 tensors incl mtp.* + vision tower + config/tokenizer/index, so the dir is layout-identical to what convert_hf_to_gguf.py already converts fine), then W += scale*(lora_b.T @ lora_a.T) in f32 per module, explicit key map language_model.model.* -> model.language_model.*, written via safetensors.torch. Verified end to end: MLX generation coherent + token-identical to base+adapter; q8_0 GGUF loads and generates at 172 t/s under llama-cli.

RED HERRING to save future-you: gguf-py/quants.py emits "RuntimeWarning: invalid value encountered in subtract/cast" during q8_0 conversion of PERFECTLY GOOD files (appears on files that produce working GGUFs; all tensors NaN/inf-scanned clean). Do not chase the warnings; chase the missing-tensor error and the generation smoke.
