# JsonConstraint silently ignored several JSON-Schema fields it did not parse: minimum/maximum on integer (used in score.rs), minItems on…

JsonConstraint silently ignored several JSON-Schema fields it did not parse: `minimum`/`maximum` on integer (used in score.rs), `minItems` on array (used in runtime.rs ~4148). Migration to llguidance changed silently-permissive → actually-enforced for these constraints. Verified per site during D-full; no production regressions but the behaviour shift is non-obvious. Likely net positive but worth flagging when adding new schemas that overlap these fields.
