# Book-report bench hallucination detector overcounts on markdown formatting. Bench "([^"]{30,240})" regex picks up the model own **bold**…

Book-report bench hallucination detector overcounts on markdown formatting. Bench `"([^"]{30,240})"` regex picks up the model own `**bold**` formatting as if it were a quotation, leading to inflated `⚠ N fabricated` counters even when the actual quote-verification layer caught zero real fabrications. Fix lives in the bench rubric, NOT in the runtime quote_verification.rs guardrail (which is correct).
