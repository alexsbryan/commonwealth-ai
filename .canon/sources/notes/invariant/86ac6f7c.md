THE ROOT CAUSE IS AN ASYMMETRY WE CREATED. The JUDGE is pinned greedy (temperature 0.0, top_p 1.0 — note 24db6e6f "one judge instrument, one sampling pin"). THE WRITER IS NOT PINNED AT ALL: there is no temperature, top_p or seed anywhere in sovereign-cli/src/deep_research_cmd.rs, so every flight samples freely on daemon defaults. We pinned the instrument and left the subject free, then attributed the subject's variance to our levers.

THE FIX, NOT YET IMPLEMENTED (operator decision pending): an experiment-only sampling pin on the draft calls, default OFF so production behaviour is untouched — exactly the shape of the judge pin. The completion API carries NO `seed` (checked: the `seed_id` fields in deep_research/icd.rs:197 and mod.rs:119 are document seeds, unrelated), so a paired same-seed design is not available without an API change; a temperature pin is the cheap path. TRADE-OFF TO STATE WHEN PROPOSING IT: a greedy-writer A/B is powered at n=2 but measures how the GREEDY writer responds to a lever, which may not generalise to the sampled writer we ship. Recommended anyway — an underpowered measurement of the real writer tells you nothing, which is strictly worse.
