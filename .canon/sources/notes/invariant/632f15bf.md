# A PEER WHOSE MANIFEST FETCH FAILS IS SILENTLY SKIPPED AS A CANDIDATE — so "nobody else advertises X" can be an artifact of a flaky bridge,…

A PEER WHOSE MANIFEST FETCH FAILS IS SILENTLY SKIPPED AS A CANDIDATE — so "nobody else advertises X" can be an artifact of a flaky bridge, not a fact about the fleet. Learned 2026-08-06 while it nearly invalidated an M6-C claim.

`gather_peer_candidates` (peer_inference.rs) does `match fetch { Some(m) => m.manifest, None => continue }`. A transport error to a peer's `/oicp/v1/capabilities` therefore removes that peer from consideration with no candidate-level record — it is an INFO log line, not an exclusion in the decision record's `excluded[]`.

HOW IT ALMOST BIT: M6-C concluded "Qwen3-4B-Q4_K_M has exactly one holder" from four CONCURRENT named calls all landing on LittleMac (min_by_key(inflight) would have split them across two holders). But BeefyMac's manifest fetch over the iroh bridge was observed failing intermittently in the same window — so the observation was equally consistent with BeefyMac holding the model and being invisible at that instant.

THE TEST THAT ACTUALLY SETTLES IT is a DIRECT NEGATIVE, not an absence of splitting: remove the known holder and ask again. With LittleMac offline, the named request resolved `named_unknown` — if BeefyMac held the id it had every reason to serve. One holder, confirmed.

GENERAL RULE: when concluding that no peer has something, a null result from the scoring/candidate path is NOT evidence — the peer may simply have been unreachable when you looked. Either remove the known holders and re-ask, or read the manifest directly. And note there is no peer-residency read on this mesh (`svrn mesh status` documents "loaded models" and prints none; `/v1/mesh/status` carries no model lists), which is why this is easy to get wrong.

WORTH FIXING: a skipped-for-transport peer should land in the decision record's `excluded[]` with a reason, so "we did not consider this peer" is visible in the same place as "we considered and rejected it". Today the two are indistinguishable from the record.
