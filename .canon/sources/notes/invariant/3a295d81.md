   ```rust
   while hook.should_yield() { ...; sleep(5s) }
   ```

   No deadline, no cap, no max-iterations. Only `should_yield()` going false exits it.
4. `should_yield()` — `commonwealth/crates/commonwealth-api/src/yield_hook.rs:54-74` — is `elapsed_since_last_foreground_inference < window`.
5. Window = `daemon.yield_to_foreground_secs`, default 60 (`sovereign-contracts/src/setup_config.rs:1105`, pinned by test `yield_to_foreground_secs_defaults_to_60`); wired at `sovereign-mesh/src/daemon.rs:2454`.
