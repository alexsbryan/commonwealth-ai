THE SEAT DOES NOT IMPLEMENT RUNGS. Operator, 2026-08-20, on finding the comaintainer session hand-writing a campaign rung: "This is all just implementation detail of the campaign right? Not sure why the comaintainer is doing it."

This is a RECURRENCE. The rule was already written (memory `feedback-plan-before-implement-seat-holds-forest`, 2026-08-12: "the seat's job is to hold the forest ... descend into files only to verify, never to implement") and was already in context. It still got lost, because the drift never presents as a decision — it accumulates one tool call at a time.

The tells, which is what was actually missing:
- You just received a WORKER'S REPORT (nc-5-corpus came back as a report the seat was overseeing). That is the shape of the work. Picking up the next rung by typing it is the drift.
- "Keep going" / "keep working autonomously" is not "keep implementing". For the seat it means: orders drafted, approvals sought, workers spawned, verdicts written.
- Delegation is standing operator-authorized here (.claude/CLAUDE.md §Delegation, cap 3 concurrent, one message). NOT delegating is an active choice needing justification, never a default.
- An order marked `approved: pending` is not a green light. nc-2b carried an explicit approval line; nc-6-atom did not, and the seat started it anyway on a two-word instruction.

WHAT IS STILL SEAT WORK: measuring/pricing an order before approving it. Finding "the order says publish Atom, but the traversal verb already exists in sovereign-core importing nothing from sovereign — 44 corpus-engine types across 176 refs" is intake, and it materially redrafted the order. The `git mv` that follows is the worker's.

STRUCTURAL CHECK before touching a file from the seat: is there an order for this, is it `approved` (not `pending`), and am I the one who should be typing? Two noes and a yes means draft the order and spawn the worker.

Cost of getting it wrong is not role purity: a seat in the trees cannot see the campaign, and it burns the context the operator relies on it to keep.
