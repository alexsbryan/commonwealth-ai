CORRECTION, supersedes 3199f234 ("a worked example is a budget"). That note read a real set of measurements and drew the WRONG cause from them, and a session acting on it would tune prompts forever.

WHAT 3199f234 GOT RIGHT — the data, all of it reproducible on wessex-hoard:
  subject section ON:  subject 46/48 · grade 2  · proposed_date 0/48
  subject section OFF: subject  9/39 · grade 32 · proposed_date 22
and four prompt variants (attributes mid-object vs last; bare `<text>`/`<number>` vs descriptive `<date or range>`; the claim sketch moved under the attributes heading) all landing near zero.

WHAT IT GOT WRONG: it concluded the model spends a per-claim ATTENTION BUDGET and that an obligatory slot displaces the optional ones beside it. There is no such budget in evidence. `attributes` and `subject` are OPTIONAL PROPERTIES in the Phase-1 JSON schema, the grammar is genuinely enforced (note e6067398 proves it by probe), and a strict grammar omits an optional object at the model's discretion no matter what the prompt says. Every number above is what optional fields do. The apparent "trade" is coincidence of timing: the subject section landed in the same builds where nothing had yet been made required.

`phase1_schema_for` sets `required = ["content","claim_kind"]` on `claim_sketch` and nothing at all on any `attributes` object — `attach_attributes` calls `set_property`, never `set_required`.

WHAT SURVIVES from the old note, and it is still worth holding: judge a prompt change by the DOWNSTREAM capability rather than a fill count (subject looked like a regression on the attribute table and was a 4.5x win on tension: candidates 155 -> 34, judged 1 -> 2). And an example that omits a slot does teach the model to omit it — the claim example shipped once without its `attributes` object and took proposed_date 14/43 -> 0/41, which is real. Both examples now share one renderer with a test.

THE STANDING LESSON, which is the reason this correction exists: before concluding a MODEL is doing something, check what the SCHEMA obliges it to do. Four prompt experiments and most of a session went into a behaviour that one line of `required` decides.
