# Llguidance ignores the custom JSON-Schema keyword x-asciiExtended (JsonConstraint enforced 2-byte UTF-8 cap on string body). Bridge layer…

Llguidance ignores the custom JSON-Schema keyword `x-asciiExtended` (JsonConstraint enforced 2-byte UTF-8 cap on string body). Bridge layer must handle UTF-8 cap separately for any schema relying on the keyword, or relax the assumption that string body bytes are bounded.
