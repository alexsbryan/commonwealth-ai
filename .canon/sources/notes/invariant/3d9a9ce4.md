Gradient cannot cross a layer with no vjp, so exactly ONE layer (index 23) is reachable. LoRA on 1 of 24 layers is not a training configuration.

mlx 0.32.0 and mlx-lm 0.31.3 are BOTH the latest on PyPI; mlx-lm-lora 3.0.0 likewise. There is no upgrade that fixes this.
