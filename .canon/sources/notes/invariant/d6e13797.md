ZERO ANSWERED IN EVERY CASE. The host does not fail one judge call, it refuses the whole judging phase for as long as the competing turn holds the slot.

THE CLASS IS HOST ADMISSION, NOT THE GATE. The shed is `sovereign-inference/src/embedded/model_slot.rs::acquire_with_queue_gauge`'s PRE-PARK gate: `predicted_wait_ms > max_wait_ms (30 s)` returns `Error::queue_shed(position, predicted_wait_ms)` without parking. It is PRIORITY-BLIND — the same rule refuses a brand-new turn's draft and a judge call belonging to a turn already admitted, and the two are not the same thing: refusing a draft returns an honest error the user sees, refusing a judge silently degrades an answer that ships anyway.

F2(b) NOT DELIVERED, and this is the reason. The fix the order pre-registered ("judge calls inherit the turn's foreground priority") lives in that admission gate — `sovereign-inference`, outside this order's seams, and a change to host-wide admission policy that peers also see. The retry half was priced and rejected on the measurement: `retry_after_secs` is 30 s and all 5 exits had calls_answered 0, so an immediate retry is shed again (the prediction has not moved) and a hint-honouring retry adds up to 30 s per shed call to a turn that is already 40-70 s — an availability cost on exactly the loaded host where the user is already waiting, against judge.rs's own "a quality lever, not an availability risk". A bounded retry with any other delay is a tuned constant, i.e. a mitigation, not the structural fix this order requires.

DELIVERED INSTEAD: F2(a) (every fail-open exit names its reason and its two counts, at ONE site — `grounding::gate::record_gate_decision`, the funnel that already owns the journal, so a future fail-open exit cannot forget) and F2(c) (the wire invariant + the lane row).

FOLLOW-UP, named so it is not lost: make the pre-park shed exempt work that continues an ALREADY-ADMITTED turn. The judge request would declare it (the OICP envelope is already threaded to every judge call via `Workload::Judge.requirements(posture)`) and `acquire_with_queue_gauge` — which already takes a `phase: &'static str` — would read it. That is a `sovereign-inference` order, not a grounding one.
