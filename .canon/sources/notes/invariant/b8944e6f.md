**Daemon brace-balance tool-stop must be gated on grammar lock (request.structured_output.is_some()), otherwise it triggers on prose `{...}`**

`sovereign-inference/src/embedded.rs` has four sites that track JSON
brace depth on the output stream and break on the balanced-envelope
condition (`tc_json_ever_opened && tc_json_depth == 0`):

- `generate_sync` (~line 1417 init, ~1555 stop)
- `generate_sync` jump-forward path (~line 1721)
- streaming variant (~line 2751 init, ~2827 tracker, ~2879 stop)
- stream-finish variant (~line 3003 init, ~3061 tracker, ~3115 stop)

All four MUST be gated on `tools_grammar_locked = tools_present &&
request.structured_output.is_some()` — i.e., the brace tracker only
runs when grammar is actively constraining output to the tool
envelope schema.

Why: without that gate, the tracker counts literal `{...}` in
prose — markdown, LaTeX, code fences. Repro: Qwopus3.5-9B-Coder
emitted "Let me set up the linear system:\n- Let x_{r,c}" inside a
free-form chat turn (no grammar lock). The `{r,c}` in markdown
balanced → daemon stopped generation at n_generated=87, declared
`stopReason=stop` with `tool_calls=0`. Downstream agent (pi) saw a
text-only response, declared `agent_end`. Run `t` of
`sovereign-agent-bench` 3.2-lights-out, 2026-05-21.

How to apply:
- If you add another path that streams from llama-cpp and tries to
  early-stop on a balanced JSON envelope, gate it the same way.
- The `</tool_call>` marker stop (shape A) is safe to leave
  unconditional — it requires the actual XML close tag in the
  output, not just balanced braces.
- The two shapes are documented in the fn-scope comment at ~line
  1402: A=marker-wrapped, B=grammar-locked bare JSON.

Related:
- [[invariant-pi-done-heuristic]] — pi declares `agent_end` when the
  assistant emits zero tool calls; this bug caused pi to do that
  every run because the daemon truncated the response mid-prose.
- [[invariant-force-tool-calls-locks-model-into-loop]] — when grammar
  IS locked (via `SOVEREIGN_FORCE_TOOL_CALLS=1` or
  `tool_choice=required`), the tracker correctly catches the
  envelope close. The fix only changes behavior in the unlocked path.

Future refactor (not yet done): the four sites are near-duplicate
40-line blocks tracking the same state. Per ARCH §10.3 (3+ copies
→ helper) they should be extracted to a small `BraceEnvelopeTracker`
helper with byte-feed + complete() methods. Pinning it as an
invariant rather than refactoring now because the priority is
shipping the gate fix; refactor is a follow-up.
