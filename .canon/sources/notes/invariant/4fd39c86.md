# WAITER LOOPS: pgrep -f <pattern> in an until-loop waiter MATCHES ITS OWN COMMAND LINE when the pattern appears in the waiter's invocation —…

WAITER LOOPS: `pgrep -f <pattern>` in an until-loop waiter MATCHES ITS OWN COMMAND LINE when the pattern appears in the waiter's invocation — multiple such waiters keep each other alive indefinitely (self-sustaining spin, observed 2026-08-08, H2 worker: three waiters on "sovereign-test.sh" deadlocked on each other, exit 144 on kill; zero effect on the real run). RULE for detached-run waiters (extends note b25059e3's detached-launch shape): wait on the JOB'S OWN PID (`until ! kill -0 $PID`) or on a completion marker in the log (`until grep -q '"t":"summary"' log`), never on a pgrep pattern that the waiter itself contains. Seat: fold into worker spawn-prompt protocol alongside the detached-launch rule.
