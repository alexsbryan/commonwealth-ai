# VAST MACHINE 51579 (RTX A6000, Virginia US, $0.4630/hr) NEVER INSTALLS THE SSH KEY — AND pod.sh up's RANKING IS DETERMINISTIC, SO RETRYING…

VAST MACHINE 51579 (RTX A6000, Virginia US, $0.4630/hr) NEVER INSTALLS THE SSH KEY — AND `pod.sh up`'s RANKING IS DETERMINISTIC, SO RETRYING RENTS IT AGAIN. Measured twice, 2026-08-05, ~$0.10 and ~20 min lost.

THE SYMPTOM. `up` waits, then: "sshd up, key refused — tolerating for 180s" then FATAL. The instance reaches actual_status=running with status_msg "success, running pytorch/pytorch_2.10.0-cuda12.8-cudnn9-devel/ssh". Manual ssh minutes later still gets `Permission denied (publickey)`.

WHAT IS NOT WRONG, all checked:
- Key IS registered on the account (id 1178540) and matches ~/.ssh/id_ed25519.pub byte for byte.
- It was registered LONG before the instance (created_at 1785889312), so the documented "key added after boot" trap does not apply.
- `vastai attach ssh <id> "$(cat key.pub)"` returns `{'success': False, 'msg': 'SSH key already associated with instance.'}` while sshd keeps refusing. THERE IS NO REPAIR FROM OUR SIDE.
- The same flow, same script, same key worked FIRST TRY on RTX PRO 5000 machine (46888730) and on a different A6000 machine (46895601, ssh up in 30s).

So it is that machine's container: whatever writes authorized_keys there did not run, and pod.sh's onstart-append workaround did not take either.

THE TRAP THAT MAKES IT EXPENSIVE: `cmd_up` ranks (verified, -reliability, price) and takes o[0]. Machine 51579 has reliability 0.9992 — the HIGHEST in the A6000 pool — so it is ALWAYS picked first. A plain retry is guaranteed to fail identically. Both my attempts picked offer 46894395/46894401 on machine 51579.

THE FIX, LANDED (uncommitted): `cloud/pod.sh up --skip-machines <comma-separated MACHINE ids>` (or `SKIP_MACHINES=` in env). Skips BEFORE ranking and prints how many offers it dropped to stderr, so a narrowed pool is never silent. Use MACHINE ids, not offer ids — offers are re-minted per search, machines persist.

STANDING USE: `--skip-machines 51579` on every RTX_A6000 rental until proven otherwise.

SECOND-CHOICE MACHINE 26608 (Delaware US, $0.4028/hr) WORKS — ssh up in 30s. It is also the cheapest in the pool.
