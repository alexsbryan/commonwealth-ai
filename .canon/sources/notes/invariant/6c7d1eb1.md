# RemoteApiProvider routing gotcha: build_request (sovereign-inference/src/remote.rs ~line 117) pins the OpenAI 'model' field from…

RemoteApiProvider routing gotcha: build_request (sovereign-inference/src/remote.rs ~line 117) pins the OpenAI 'model' field from request.model_id, NOT the provider's own self.model_id — with request.model_id=None it sends an empty model field and the daemon falls back to its DEFAULT slot. So constructing RemoteApiProvider::new(url, key, 'fast', ctx) does NOT route to the fast slot unless each CompletionRequest also sets model_id=Some('fast'). Symptom: multi-model benches silently serve every model from one slot; deterministic (logprob) elicitation exposes it as bit-identical results across models, while sampling noise hides it. Fixed in bench_cmd/mechanism_fidelity.rs elicit/elicit_logprob by setting request.model_id.
