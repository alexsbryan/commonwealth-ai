# MTP slot demotion is structural, not field-nulling. MtpSession::new calls upstream's common_speculative_init which installs…

MTP slot demotion is structural, not field-nulling. `MtpSession::new` calls upstream's `common_speculative_init` which installs `set_embeddings_pre_norm(true)` on the target context with no inverse. Pre-2026-05-20 quarantine code did `slot_ctx.mtp_session = None` and left the target intact — every subsequent decode returned `Decode Error -3` for the rest of the slot's life. The 2026-05-20 refactor encodes the invariant in `SlotInferenceMode { SingleToken, Speculative }` so the hybrid state is unrepresentable. Demote = drop session + draft + mutated-target and rebuild target via captured `MtpRebuildParams`. Probe at construction (1-token `target.decode → session.process → session.begin`) catches MTP-named ggufs that lack heads at load time rather than at first request. See sovereign-inference/src/embedded.rs::SlotInferenceMode + demote_to_single_token + try_upgrade_to_speculative + probe_mtp_roundtrip.
