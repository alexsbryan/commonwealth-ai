TIMING. Two full runs, 1,800 s budget. Run 1 (chaos at six probes): 1,745 s, and it fit ONLY because `synth` was SKIP(budget) and never ran. Run 2 (chaos cut to four probes, `--mint`): all eight lanes started, total 1,800 s, and `synth` was killed at its 666 s cap. Per-lane seconds, run 1 / run 2:

So eight lanes DO NOT fit 1,800 s on this host under contention. The order's stop condition was applied: one cut, one re-measure, no widening. The two cheapest levers left, neither taken because the order did not authorise them: chaos-monkey's fixed startup (it loads the wiki graph — 51,845 articles / 7.8M edges — and a 1.5M-atom meta-atlas before its first probe), and the lane ORDER in `quality/check-lanes.toml`, which today puts the two most expensive lanes late so they are the ones starved.

THE HOST IS THE DOMINANT VARIABLE. Primary-slot decode measured 50.7 tok/s quiet, 45.7 tok/s in run 2, and 17.8 tok/s in run 1 — a 2.8x spread on the same binary and the same bank, with load averages of 3.7 / 22 / 32. Any wall-clock or latency bar on this machine has to be read against that. Concretely: the chat-ask `per-stage ceilings` row (1.5x quiet-host medians, pre-registered) blew five stages in run 1 and exactly one in run 2 — `retrieval 298 ms > 290`, eight milliseconds.

THREE FINDINGS THAT ARE NOT NOISE — same verdict in both runs, across that 2.6x:

1. `knowledge-gym / 05_noresults_honesty` scores 0/3. The model answers "I do not have access to real-time information" WITHOUT calling `knowledge_lookup`, so `should_call_knowledge_lookup` and `expected_first_tool` fail while every other predicate passes. `01_corpus_definitional` 3/3 and `06_fabricated_id_blocked` 3/3 are the controls that separate this from a broken harness.
2. `chaos-monkey / absent-embassy-country` confabulates. Asked which country's embassy employs Mr Vladimir — a fact the corpus does not carry — the answer asserts "the Russian embassy" with `asserted_value_grounded: false`. This is the blatant-confab catastrophe rule, firing on a real run.
3. Issue #57's signature is INTERMITTENT, roughly one run in three. `gate outcome [q1]` failed in two of three chat-ask runs on quotes released with `located: 0` and passed in the third. A single run could not have said this; three warm runs per question is why the lane can.
