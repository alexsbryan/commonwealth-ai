Mechanism-fidelity negative-control validity REQUIRES Case.narrative to stay mechanism-free (no wealth/liquidity/ties/rate hints). The Stripped (feature-stripped) render shows only identity text; because DIR perturbations (DirP1/DirP2) change hidden feature values but hold identity fixed, stripped(base) and stripped(perturbed) prompts are byte-identical, so the control CANNOT see what changed and thus must FAIL sensitivity. Encoding any feature into the narrative silently defeats the leak detector. Guard: case.rs test narrative_is_mechanism_free. Files: sovereign-eval/src/mechanism_fidelity/{case.rs,perturb.rs}.
