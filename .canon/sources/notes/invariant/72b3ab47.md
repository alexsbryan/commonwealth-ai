CONTAMINATION PASS: A "CLEAN" VERDICT IS ONLY MEANINGFUL WITH A POSITIVE CONTROL, AND IT DOES NOT COVER PRETRAINING MEMORIZATION (2026-07-31, verifier-v0 Stream B).

Two things future sessions must not repeat.

1. `canary_hits` IS NOT A POSITIVE CONTROL. It checks for benchmark canary GUIDs (contamination_pass.py:75, :190-192); 0 hits is the expected/good result, not a failed control. Nothing in a normal run proves the 13-gram detector can fire at all. Before trusting CLEAN, plant a real test doc: one row with an LLM-AggreFact `doc` in `evidence_chunks`, one with a >=13-word verbatim FaithBench `source` span as `claim`, one genuine row as negative. Correct behaviour = doc_collisions 1, claim_collisions 1, negative 0, verdict flips to COLLISIONS FOUND. Verified working 2026-07-31.

2. BUG FOUND AND FIXED BY THAT CONTROL: `colliding_training_rows` was incremented only on the evidence path (:177), never the claim path (:181-185). A claim-only collision showed in `per_group.claim_collisions` but was INVISIBLE in the top-line count — the two halves of the report silently disagreed. Fixed with a both-surfaces guard (a row colliding on both counts once). Any contamination report read BEFORE 2026-07-31 must not be trusted on its top line for claim-surface overlap. Chaos and SEP verdicts are unaffected: both have claim_collisions 0 in every group.

3. THE PASS MEASURES TEST-SET OVERLAP, NOT PRETRAINING MEMORIZATION. The plan of record predicted SEP would come back nonzero because "SEP is heavily crawled". It came back CLEAN (19,451 rows, 0/0/0) — correctly, because the pass shingles against LLM-AggreFact + FaithBench TEST DOCS, which are news/dialogue summarization sources with no reason to share 13-grams with philosophy-encyclopedia prose. "Crawled into pretraining" is a DIFFERENT risk this pass structurally cannot detect, and it stays live: a verifier trained on SEP may look strong on SEP-like content because the BASE MODEL memorized SEP. Keep the two risks separate on the eval card; do not let a CLEAN contamination report be cited as evidence against memorization.
