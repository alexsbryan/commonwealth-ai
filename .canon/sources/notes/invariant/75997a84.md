Deployed dispatcher on Alex's MacBook is DEBUG, not release (since 2026-06-10): ~/.local/bin/sovereign → target/debug/sovereign-cli, and `sovereign daemon restart` therefore launches target/debug/sovereign-cli-daemon. The earlier session-frame invariant "sovereign code brief execs the RELEASE sibling" is stale for this host. To deploy a change to the daemon or any `sovereign` verb here: build the DEBUG siblings (cargo build -p sovereign-cli -p sovereign-cli-dev -p sovereign-cli-daemon -p sovereign-cli-llm) and restart; a release-only build (dev-release.sh) is invisible to the deployed toolchain. The CLI's own stale-warning ("sovereign-cli-dev binary is Nm older than the dispatcher") is the tell.
