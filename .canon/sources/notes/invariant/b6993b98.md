NEXT-EDIT ON A CHAT MODEL: THINKING MUST BE SUPPRESSED, AND IT TAKES BOTH TRANSPORTS (measured 2026-08-07, 60-case gym/next-edit/gen bank, gate forced open).

With reasoning ON, a 35B-A3B chat primary scored 0/30 — it emits ~1044 tokens of `reasoning_content` before its first answer byte, against the 64..1024 the lane grants (next_edit_model.rs `max_tokens`), so EVERY case finishes `length` with EMPTY content. With reasoning OFF, same weights and same prompt: 21/30 useful, 0 wrong edits, p95 2576ms — against a 1.5B next-edit specialist's 19/30, 0 wrong, p95 828ms. Quality is indistinguishable at n=30 (the phase-0 power analysis put 27/30 vs 25/30 at p~0.45; resolving a 10-point gap needs ~199 positives/arm). The specialist's real win is ~3x LATENCY, not correctness.

THE TWO TRANSPORTS ARE NOT INTERCHANGEABLE. `chat_template_kwargs.enable_thinking=false` is what the Jinja template branches on; `think_budget=0` drives the daemon's `/no_think` injection. A budget of 0 ALONE was verified INERT on this chat template (811 chars of reasoning_content still emitted, content empty, finish=length). Set BOTH. In llama-server the equivalent is the `--reasoning off` CLI flag; `--reasoning-budget 0` is likewise inert there.

`ConsultPlan::suppress_thinking` is derived from the PROMPT VARIANT (`Prompt::Chat | Prompt::ChatSystem`), never from a format-string allowlist, so a new chat dialect inherits it structurally. Both the daemon route AND examples/next_edit_score.rs read it — the scorer's own comment promises byte-identical requests (ARCH 10.6), and if only one carried the knob the bank number would describe neither model.

DIALECT MATTERS TOO: `instinct` scored 4/30 (28 invalid) vs `region_instruct` 21/30 on the same weights. RegionInstruct (the NextEditFormat default) is already correct for a general chat primary; instinct is Continue's model-specific register.

CAVEAT ON THE 21/30: `--force-consult` makes usefulness a CEILING and safety a FLOOR. Both arms were measured identically so the comparison is fair, but 21/30 is an upper bound on what the real gate would deliver.
