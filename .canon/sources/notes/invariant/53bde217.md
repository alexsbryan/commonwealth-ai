FIELDGLASS SIDECAR WRITE RULE (changed 2026-08-07, artifact C of docs/FIELD_VERDICTS.md): the degrade guard in code_fieldglass/mod.rs protects ONLY the default baseline path. An explicitly redirected sidecar (--out/--json) is ALWAYS written, degraded or not — the seat's landing field-diff (co-review.sh --field) depends on exactly this, and before the change a --no-dup --out render silently produced HTML with no JSON (watched-fail confirmed on the pre-change binary).

Do not "fix" this back to guarding all writes: the baseline-preservation invariant (a degraded render must not replace tomorrow's delta baseline) is about the DEFAULT path, and redirected writes are structurally incapable of touching it. Both paths announce themselves on stdout (§9.1): "degraded render written to explicit path ... default delta baseline untouched" vs "delta baseline at ... preserved".

Also load-bearing in co-field.py diff: growth (files[].lines) is walked live at render time and never SCIP-gated; coupling (fan_in, flow_edges) is SCIP-fed and emits could-not-judge when the index does not cover the reviewed ref (merge-base --is-ancestor). "No structural delta" and "nothing measurable" (all changed paths off-field, e.g. python/docs landings) are DIFFERENT verdicts and printed differently — collapsing them was caught live on the first real run.
