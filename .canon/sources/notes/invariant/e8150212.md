P1 desktop rendering witness — two facts that decide whether a "flag-on" desktop run is real or vacuous (order native-grounding-p1-desktop, session 2).

1) WHICH PROCESS READS THE FLAG. On the desktop path the Runtime is built in the DESKTOP process (sovereign-desktop/src-tauri/src/state.rs:1508 Runtime::new, :1529 with_rerank), not in the daemon — the daemon supplies model slots over HTTP. SOVEREIGN_NATIVE_GROUNDING is read in exactly one place (native_grounding::admission::native_grounding_enabled, admission.rs:153) inside whichever process runs the turn. The real-mode e2e harness spawns BOTH the managed daemon and the app with `{...process.env}` (tests/e2e/real/global-setup.ts:896, :994), so exporting the flag before `npx playwright test -c playwright.real.config.ts` puts the arm on both — no operator-daemon restart needed.

2) NO RERANKER = NO EVIDENCE, SILENTLY. H1 needs a cross-encoder: with none wired and no rerank_score left on the chunks, admit() returns NoInstrument (admission.rs:264), native_verdict is None (knowledge_query.rs:678), and answer_segments is never computed (streaming.rs:1751 — the Option is what makes the wire field null). A flag-on desktop run without SOVEREIGN_RERANK_MODEL_PATH therefore renders EXACTLY the flag-off screen while reporting itself as flag-on. The desktop loads its reranker in-process via reranker_standalone::load_from_env(), and the daemon's install_rerank_slot SOFT-FAILS on a bad path (inference.rs:247). Keep the reranker set in BOTH arms (it changes which chunks survive retrieval — same reasoning as bench/calibration/ab/run_ab.sh) and refuse the run when it is unset.

Both are encoded structurally in tests/e2e/real/native-grounding-p1.real.spec.ts (beforeAll refusal) and tests/e2e/scripts/p1-desktop-render.sh (pre-run guards + :9741-free check).
