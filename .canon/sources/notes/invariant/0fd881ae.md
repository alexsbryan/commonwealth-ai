# Llguidance additionalProperties defaults to TRUE (spec-compliant); JsonConstraint defaulted to FALSE (non-spec). Bridge layer that migrates…

Llguidance `additionalProperties` defaults to TRUE (spec-compliant); JsonConstraint defaulted to FALSE (non-spec). Bridge layer that migrates a schema from JsonConstraint MUST inject `additionalProperties: false` explicitly or the model gains freedom to emit unknown keys. Audit §3.A flagged HIGH risk during migration. Pinned by from_json_schema_rejects_incomplete_envelope test (strict-closure pinning).
