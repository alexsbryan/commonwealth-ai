# HOLDING A NODE'S IROH DIAL STRING IS NOT A CREDENTIAL. The acceptor routes on (ALPN, dialer key), never on ALPN alone.

HOLDING A NODE'S IROH DIAL STRING IS NOT A CREDENTIAL. The acceptor routes on `(ALPN, dialer key)`, never on ALPN alone.

An iroh endpoint accepts anyone, and the dial string that reaches it is PUBLIC — it rides in every invite's `dial=` and is gossiped as `MemberRecord.node_pubkey`. The acceptor forwards by `TcpStream::connect("127.0.0.1")`, and `client_auth_layer` admits a loopback peer before reading a bearer. So routing on ALPN alone handed every dial-string holder the whole client API with no credential. Reproduced, not inferred: `sovereign-mesh/tests/iroh_dialer_admission_e2e.rs::routing_on_alpn_alone_is_the_hole_this_closes` wires the old routing and gets a 200 for a stranger presenting nothing.

What the QUIC handshake DOES prove is the dialer's Ed25519 key (`Connection::remote_id()`), which is the same key the mesh gossips. `AcceptorRoutes::forward_for` (`sovereign-mesh/src/iroh_access.rs`) is the ONE decider:

- `CLIENT_ALPN` — a MEMBER reaches the daemon's own client listener with no bearer. That is not a shortcut: peer federated inference carries no `Authorization` header at all (`TrafficClass::Inference | StatusProbe`, `MeshInferenceProvider` off `PeerInferenceEndpoint.base_urls`), and membership-by-key is the credential it presents instead. A STRANGER is downgraded, not refused — routed to the bearer-checking guest listener, which is the posture a LAN caller meets, so `/status` and `/oicp/v1/capabilities` stay readable by a node that could not yet hold anything. If that listener did not bind, a stranger is CLOSED; the trusting listener is never a fallback.
- `RPC_ALPN` — MEMBERS ONLY, no downgrade. It forwards to a raw ggml rpc-server that authenticates nothing.
- `GUEST_ALPN` — any dialer; the listener behind it reads the bearer.
- `ALPN` (internal) — any dialer, DELIBERATELY: a joiner is not a member yet and `/internal/join` is how it becomes one. Gating it makes the mesh unjoinable over its own transport.

STILL OPEN, and named rather than buried: the internal router's non-join routes (model transfer, index serve, knowledge fan-out, rpc-warm, scheduling) are reachable by any dial-string holder. `gossip_authorized` and the join key cover the sensitive ones; the rest carry nothing. Closing it needs a join-only listener for non-members — the same shape as the guest split — not another predicate.

Membership is read LIVE per dial (`AppState.inner.mesh`, `removed_at` excluded), never snapshotted: a departed node loses reachability with its membership, and a fresh one gains it without a restart. `iroh_access::admits_no_one()` is the fail-closed default, so a host that forgets to wire a check narrows access rather than widening it.
