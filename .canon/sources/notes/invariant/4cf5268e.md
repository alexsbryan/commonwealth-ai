CONFAB IS NOT A SUBSTITUTE FOR THE CLAIM-BY-CLAIM READ — instrument limitation, proven twice, 2026-08-13 (gate-bigo-prefill-tax lands B and C).

THE CLAIM THAT FAILED. The order named the CONFAB probe arm as "the corroborating second instrument" for judge-input changes. On land C it read completely flat through a judge that had just cleared FOUR engineered fabrications:

  metric                    baseline-0813   land B    land C
  blatant-confab-rate            0.05        0.05      0.05
  grounding-fidelity             0.92        0.92      0.91
  distractor-evasion             1.00        1.00      1.00
  dev competence-when-present    0.84        0.84      0.84
  dev honesty-when-absent        1.00        1.00      1.00

Meanwhile dev not_supported fell 27 -> 15 and the naive always-supported ceiling rose 0.6400 -> 0.8125.

THE MECHANISM, which is the useful part: CONFAB scores WHETHER THE ANSWER PRESENTS A VALUE ABSENT FROM EVIDENCE. It is an instrument aimed at the drafter's output. The failure mode land C exhibits is the JUDGE CLEARING A FABRICATION — and on these probes the gate then ANNOTATED rather than removed the offending text, so the answer's presented values barely moved. The two instruments are not measuring the same event, and the second one is downstream of a stage the first one is upstream of. It is corroborating for DRAFTER-side changes and structurally blind to JUDGE-side permissiveness.

PROVEN TWICE. Land B: 3/3 pass, CONFAB flat, one (c) found only by the claim-by-claim read. Land C: 3/3 pass, CONFAB flat, four (c)s found only by the read — including one with byte-identical claim text and an opposite verdict.

WHAT ACTUALLY DETECTS IT. Only the claim-by-claim (a)/(b)/(c) classification of every dropped catch: (a) artifact-removal, (b) the rewrite no longer asserts the claim, (c) a real fabrication now cleared. Then, for each claim the after-arm marks VERIFIED, grep its specifics against the evidence the judge actually saw. On land C, four claims marked verified contained terms with ZERO hits in 21k-36k chars of evidence. The read is manual, it is the only thing that has ever caught this class, and it should be a standing requirement of any judge-input arm rather than a per-order instruction.

COROLLARY FOR THE FROZEN BAR: ">=1 not_supported per probe" cannot see a traded catch either — a probe that gives up one engineered fabrication while still catching six others passes. Two instruments (frozen bar, CONFAB) both reported PASS on a land that does not ship. Neither is wrong; both are coarse in the same direction, and their agreement is not independent evidence.
