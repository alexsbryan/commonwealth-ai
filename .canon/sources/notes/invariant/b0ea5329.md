# A new top-level svrn verb costs FIVE registrations, and four of them are tests you only see after you commit.

A new top-level `svrn` verb costs FIVE registrations, and four of them are tests you only see after you commit.

Landing `svrn quality` (order quality-check-lean, 2026-09-04) needed, in sovereign-cli:
1. `mod <name>_cmd;` + the dispatch `match` arm.
2. `DEV_VERBS` (if dev-tools-gated) AND `ALL_VERBS` (sorted — `all_verbs_is_complete_and_sorted` pins it) AND `DEV_SUBCOMMANDS`.
3. `sovereign/docs/cli-contract.toml` `[[command]]` rows, one per PATH (`quality check` and `quality lane` are two) — else `cli_contract_code::direction2_dump_commands_matches_manifest_verbs`.
4. `sovereign/docs/CLI_REFERENCE.md` `### svrn <verb>` section — else `cli_contract_docs::forward_every_manifest_command_is_documented`.
5. A `[[journey.step]]` that DRIVES it, or a `[[stranded]]` row — else `cli_contract_journeys::every_canonical_verb_is_journeyed_or_stranded`.

Two traps measured on the way:
- `[journey.step.expect]` accepts ONLY `exit`, `stdout_contains`, `stdout_absent`, `stdout_non_empty`. There is no `stderr_contains`, so a verb whose interesting output is a REFUSAL on stderr needs a different assertable step. One bad key in the manifest fails 40 tests at once, because every cli_contract test parses the file first — which is what a peer's workspace run reported as "11 failures attributed to your commit".
- A verb whose real journey is a ten-minute model run should be journeyed on a CHEAP structural rule instead. `svrn quality check --budget-secs 0` asserts the budget rule (every lane could-not-judge, exit 4, "out of budget" on stdout) in about a second, and it also proves the lane table parsed.

And: a product module in sovereign-cli-llm may not name `sovereign_eval` — `backstage_boundary::bench_cmd_is_the_only_module_naming_the_eval_harness` fails. If you need a decision that lives in `bench_cmd` and returns an eval type, add a wrapper in `bench_cmd` returning a plain type (see `chaos_monkey::abstained_from_gate_signal`) rather than importing the harness's vocabulary.
