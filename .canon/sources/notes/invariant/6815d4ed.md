# Stack Exchange knowledge corpus is installable end-to-end from the desktop with no manual prep. Install button → POST…

Stack Exchange knowledge corpus is installable end-to-end from the desktop with no manual prep. Install button → POST /internal/corpus/install → engine.ingest(CorpusSpec::Builtin("stackexchange-knowledge")) → registry resolves bundled recipe → BulkDownloader downloads each .7z to `~/.sovereign/downloads/stackexchange-knowledge/` → StackExchangeExtractor finds the .7z files in that dir, calls sevenz_rust2::decompress_file once per archive (writes a `.extracted` sentinel for idempotency) → walks the extracted subdirs for Posts.xml → QuestionWithAnswers grouping → KnowledgeDensity filter (no-op on charter sites; only fires on stackoverflow.com) → passthrough chunker honors embed_text breadth summary → LanceDB index.

Once installed, the daemon retrieval path picks it up automatically. `runtime.rs:search_corpus_indexes` calls `engine.installed_indexes()` which walks `~/.sovereign/indexes/` and returns every entry whose CorpusKind is Knowledge (corpora with no `source_path` set on the index = Knowledge by default). Stack Exchange knowledge gets searched on every chat turn alongside Wikipedia and any other knowledge corpus. Same for opencode and any other client of the daemon `/v1/chat/completions`.

Default scope is the small charter sites (Software Engineering, DBA, Security, DevOps, Skeptics SE — ~150 MB compressed). The 17 GB Stack Overflow Posts archive is opt-in via expand to keep first install ~5 minutes. Engineering enrichment domain is registered but the prompt set is stubbed (todo!) — keep `[enrichment].enabled = false` until prompts land; without enrichment the corpus still works for chat retrieval (FTS+vector). 

Crates: sevenz-rust2 v0.21 with default-features = false, features = ["bzip2", "util"] for runtime; ["bzip2", "util", "compress"] in dev-dependencies so tests can build fixture archives.

Tests: corpus-engine has 779 lib tests passing (added 14 new). The 7z roundtrip is exercised by extractors::xml::tests::extractor_auto_extracts_seven_zip_archive_in_directory.
