# build_self_manifest must advertise symmetric commonwealth/fast + fast aliases for the Fast slot — mirror of the existing primary-alias…

build_self_manifest must advertise symmetric `commonwealth/fast` + `fast` aliases for the Fast slot — mirror of the existing primary-alias block. Without this, mesh load-balancer rejects `commonwealth/fast` requests upfront (judge 503) even though the local slot-alias map at sovereign-mesh/src/daemon.rs knows about the alias. Surfaced during URL-constraint gym v3 → v4 validation. See [[project_fast_slot_alias_advertisement]].
