# Local mac desktop release + updater artifacts: when the Tauri DMG step dies on Finder/TCC, cargo tauri build exits before creating updater…

Local mac desktop release + updater artifacts: when the Tauri DMG step dies on Finder/TCC, cargo tauri build exits before creating updater artifacts even with bundle.createUpdaterArtifacts=true — so svrnmesh.app.tar.gz+.sig never appear. Fix: after the DMG fallback, run a second pass 'cargo tauri build --target <triple> --bundles app --config src-tauri/tauri.release.conf.json' with TAURI_SIGNING_PRIVATE_KEY(+_PASSWORD) exported; it re-bundles in ~min and emits+signs the archive. Rename to svrnmesh_<ver>_<aarch64|x64>.app.tar.gz before upload (endpoint pattern + cross-arch collision). Verified 2026-07-10 for desktop-v0.1.19; sig key ID 98763AFF12C7480C matches embedded pubkey.
