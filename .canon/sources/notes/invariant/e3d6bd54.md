macOS portability traps fixed 2026-05-27 in the TDD/agent-tools safety layer (both were silent on macOS, green on Linux): (1) PythonSyntaxValidator shelled out to GNU `timeout`, absent on macOS by default → spawn Err → fail-open → the pre-write validator caught ZERO broken Python on every Mac. Fix: timeout_prefix() resolves timeout→gtimeout→direct python3. (2) Workdir::check_safe canonicalizes the input; macOS firmlinks /etc→/private/etc and /var→/private/var, so is_system_path only knew /etc and misclassified bare /etc as NotAGitRepo instead of SystemPath — a real hole in the destructive-write guard. Fix: ROOTS includes /private/etc + /private/tmp (NOT /private/var — tempdirs live in /private/var/folders), and the $HOME compare canonicalizes home. Lesson: any guard/validator that shells a coreutils binary or canonicalizes a path needs a macOS check.
