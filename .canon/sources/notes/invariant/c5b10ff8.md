# svrn project refresh --name X --local REBUILT THE WRONG PROJECT — fixed 2026-08-07, and the shape of the bug is worth remembering.

`svrn project refresh --name X --local` REBUILT THE WRONG PROJECT — fixed 2026-08-07, and the shape of the bug is worth remembering.

THE BUG: `refresh.rs` parsed `--name` into `explicit_name`, used it on the daemon-nudge path, then on the LOCAL path did `let _ = explicit_name;` and derived the target from `find_repo_root()` — the caller's cwd. So the flag was accepted, silently discarded, and the command rebuilt whatever repo you were standing in while printing ✓ and that repo's symbol counts under no name at all. Observed: `--name go-demo --local` from the commonwealth-ai workspace re-exported commonwealth-ai and printed "250484 symbols (+0)" — go-demo is three Go files with no Rust in it.

WHY IT MATTERED MORE THAN IT LOOKS: `svrn doctor`'s own repair hint for an empty SCIP graph is EXACTLY this form (`svrn project refresh --name <corpus> --local`). So the advice doctor gives for a broken index refreshed a different project, reported success, and left the finding standing — an operator following it would loop forever.

THE TELL, for next time: `let _ = <parsed_flag>;` is not a lint suppression, it is a discarded promise. Someone saw "unused variable" on one branch and silenced the compiler instead of asking why the branch ignored an argument the user supplied. Grep for `let _ =` over parsed CLI args when a flag "doesn't seem to do anything".

THE FIX: the local arm resolves the project's root from `sovereign_mesh::projects::Registry` by name, prints `→ <name> at <root>` so the target is visible before the work starts, and REFUSES an unregistered name (exit 1, listing what is registered) rather than falling back to the cwd — absence is reported, never defaulted (ARCH §18.3). `explicit_name` also now wins for the corpus_id the rebuild is written under, else the rebuild would land in a different key than the registry entry it resolved.

VERIFIED after the fix: `--name go-demo --local` → "→ go-demo at /…/go-demo", "Exporting go... ✓ go: 10 symbols", +10. `--name react-demo --local` → typescript, 14 symbols. `--name no-such-project --local` → exit 1, refuses, lists commonwealth-ai/go-demo/react-demo.

Rebuild `sovereign-cli-dev` for this (the dispatcher execs the sibling; editing refresh.rs and rebuilding only sovereign-cli is a silent no-op).
