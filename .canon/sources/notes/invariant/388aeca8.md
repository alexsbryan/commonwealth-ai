jina-reranker-v3 uses a score-token-logit protocol: read logit for `<|score_token|>` (id 151669) at the position after a trailing `<|rerank_token|>` (id 151671). NOT llama.cpp BERT-style pooling_type=Rank — pooled rank returns all zeros. Different reranker family will silently produce zero scores. rerank_smoke.rs is the canary: relevant docs should score 0.5-1.0 above irrelevant across three test queries.
