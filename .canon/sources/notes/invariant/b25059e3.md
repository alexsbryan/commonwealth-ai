Long bench runs must be launched DETACHED (nohup + disown), never as a harness background task. 2026-08-07: a 43-probe `svrn bench chaos-monkey run --gv-shadow` was started via the Bash tool's run_in_background. The session was then terminated by an API infrastructure error; when the harness cleaned up that session's background task it killed the chaos process at probe 35/43. The ResultRow .jsonl is only written at the END of the run, so 40 minutes of daemon time produced nothing but a partial transcripts sidecar (the sidecar streams per probe, which is the only reason any evidence survived). Relaunch shape that survives: `cd <worktree> && nohup sovereign bench chaos-monkey run ... > log 2>&1 < /dev/null & disown`, then poll with a separate `until ! pgrep -f "bench chaos-monkey"; do sleep 30; done` waiter — the waiter is disposable, the run is not.
