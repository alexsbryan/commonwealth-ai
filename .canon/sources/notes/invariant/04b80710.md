# --relay-only DOES NOT PIN THE RELAY LEG. Any measurement that claims to be on the relayed path without checking path= is contaminated, and…

`--relay-only` DOES NOT PIN THE RELAY LEG. Any measurement that claims to be on the relayed path without checking `path=` is contaminated, and it will read HIGH — which is the direction that gets believed.

MEASURED 2026-09-09 by the media-bridge de-risk bench. `RelayOnlySelector` returns an EMPTY selection when no relay path is currently open, and an empty selection KEEPS THE CURRENT PATH rather than forcing a relay. So the flag is a preference, not a constraint. Two of three runs consequently ran at loopback speed reporting `path=mixed`; only the run that happened to START relayed measured anything relay-shaped, and its 7.8 Mbit/s is an UPPER BOUND rather than a reading.

WHY THIS IS DANGEROUS RATHER THAN MERELY WRONG: 7.8 Mbit/s sits exactly inside the prior that `WORK_PLANE.md` already writes down for relayed throughput ("single-digit to low-tens"). A contaminated number that agrees with your prior is the one you accept without checking. The same trap applies to any future relay-floor work — including Track A2's tensor tunnel bench, which shares this unknown.

HOW TO MEASURE THE RELAY LEG HONESTLY: gate every individual reading on the run's own `path=` line reading `relayed`, and DISCARD any run that reads `direct` or `mixed` rather than averaging it in. Report the discard count alongside the kept runs — a bench that silently drops half its samples is its own §18.3 problem. `svrn mesh transport` and `iroh_access::PeerTransportPath` (direct | relayed | mixed | idle, plus active_direct_addrs) are the surfaces that answer it.

Raw evidence kept in the tree under `sovereign/bench/media_bridge/relay-leg-CONTAMINATED.stdout`, named that way deliberately so nobody quotes it as a result.

RELATED CAPABILITY GAP the same bench found: the cross-machine reading could not be taken at all, because there is no way to START a process on a peer — no ssh, and no mesh remote-exec surface. That, not the transport, is what blocks the pre-registered two-machine bar.
