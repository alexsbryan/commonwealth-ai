NATIVE GROUNDING P1 (order native-grounding-p1-desktop, 2026-08-10): SOVEREIGN_NATIVE_GROUNDING=1 is now a DISPLAY flag. H1 admission runs as telemetry only — every admission event carries `enforced = false` — and it decides nothing.

TWO enforcement sites existed, not one. The parity plan (§4.1) named only the native decline branch in handlers/knowledge_query.rs. The SECOND was `grounding::abstention_action`, which took the turn's gate action from `verdict.to_gate_action()` whenever H1 had run. That diverged from flag-off in BOTH directions: a prose decline under a typed `Answer` stayed "released" on the flag-on arm while flag-off reclassified it to "abstained_decline", and a confident answer under a typed `Abstain` became an abstention. The epistemic ledger, collaboration surface and honesty scorer all read that string, so this was a real quality-affecting divergence and it breaks A1 (the plan's pre-registered kill for the whole phase). Both sites are DELETED, not guarded: `abstention_action` no longer takes a verdict parameter at all, and `DeclinedBy::NativeH1` is gone. If you are re-enforcing a verdict (P3c), you must re-add a branch and its comment — that is the point.

CHUNK IDs IN SEGMENTS ARE POOL INDICES, NOT CORPUS HANDLES. `segments_for_display` is handed chunk TEXTS, so `SegmentKind::Grounded.chunk_id` is the index in the sealed pool. Do NOT resolve it by index against `metadata.retrieved_chunks` — the gate's evidence pool is filtered (summaries dropped) and reordered relative to the retrieved set, so index-matching opens a DIFFERENT passage under a correct-looking badge. The one correct resolver is `EvidenceContext.chunk_targets`, built parallel to the same pool; streaming.rs fills `SegmentKind::Grounded.address` from it. `None` there means "found in your sources, nowhere to send you" and must render as that, never as a link.

The citability bar is `grounded_addressed == grounded`, traced per turn ("native-grounding: answer segmented for display") and scored offline by sovereign/bench/calibration/ab/p1_verdict.py.
