=== WHY THIS MATTERS MORE THAN A FLAKY NUMBER ===
A zero for a question that never ran is a DEFAULTED value standing where an absence belongs (§18.3). It is indistinguishable in the report from "the system answered and the judge scored it zero", which is the exact conflation §18.2 exists to prevent. It lies toward BAD news here; the same mechanism lies toward good news whenever a baseline row is the missing one.

`stream_wall_ms == 0 and retrieved_chunk_count == 0 and answer == ""` means NEVER RAN. Do not adjudicate it as a score.

NOTE: `embed_ms` / `search_ms` are 0 for EVERY row in synth mode, executed or not — they are not populated on this path, so they are NOT the discriminator. Use stream_wall_ms.
