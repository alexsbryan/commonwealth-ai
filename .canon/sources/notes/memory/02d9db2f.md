User preference: no emojis in code, comments, UI copy, or docs

The user does not want emojis — in code, comments, UI copy, scaffolded templates, or
docs. (2026-06-16: flagged after I sprinkled decorative `📋`/`✏️` into the Federalist
mesh-app copy-paste template; also replaced `✓`/`✕` glyphs I'd added.)

Why: clean, professional surfaces; the codebase's own style uses plain text + a few
monochrome geometric/UI glyphs, not decorative pictographs.

How to apply: no pictograph emojis (📋 ✏️ 🚀 etc.). Plain-text labels for "edit
here"/"copy this" guidance. Arrows (`→`) and the existing geometric marks (◇ ▷) are fine —
they're typography, not emojis, and match the codebase. When unsure, prefer plain ASCII.
Don't add `✓`/`✕`/`⚠` as new decoration; reuse a pre-existing convention only if the
surrounding file already uses it.
