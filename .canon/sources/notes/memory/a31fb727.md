# bench all --synth drives runtime.handle_message_stream (same code as desktop chat) for end-to-end propagation gates

bench all --synth drives runtime.handle_message_stream (same code as desktop chat) for end-to-end propagation gates

`sovereign bench all` covers two retrieval surfaces:

- Retrieval (default). Subprocesses `eval run` without `--synth`. Bypasses `Runtime::search_corpus_indexes` and calls `CorpusIndex::search_with_rerank` directly per `installed_indexes()`. Measures embed + BM25 + vector + atlas-tier boost + cross-encoder reranker — every primitive the chat path also uses. Cheap: zero LLM chat calls per question.
- Synth (--synth flag). Subprocesses `eval run --synth`. Drives `runtime.handle_message_stream` — the exact same entry point the desktop chat surface uses. Adds coverage of: intent classifier, router (KnowledgeQuery / DeepQuery / etc.), sensitive-corpus oracle, kind filter, synthesis LLM. Expensive: one chat call per question (~5-30s on the loaded model).

Why two modes: retrieval-mode is fast enough for the dev loop. Synth-mode is the truthful propagation gate. Tuning retrieval improvements with the fast mode and confirming with synth-mode before declaring done.

Why this matters: retrieval-mode bench numbers can be excellent while chat experience stays bad. Obsidian smoke 2026-05-15 showed retrieval 0.96 fact / 1.00 src but synth 0.56 fact / 0.75 src — the chat-only layers (classifier routing, sensitive filtering, synthesis model selecting which retrieved chunks to actually surface) drop 40pt of facts and 25pt of sources between retrieval and the answer. Without synth-mode that gap is invisible.

How to apply:

```bash
# Tune retrieval primitives (fast)
sovereign bench all --filter <bench>

# Before declaring chat-side propagation done, run synth
sovereign bench all --filter <bench> --synth

# Synth produces a separate baseline at baselines/<bench>-synth/
# so retrieval-mode and synth-mode don't overwrite each other.
```

Lever map for the gap between retrieval-mode and synth-mode:

| Drop seen | Owner |
|---|---|
| fact_recall (retrieval high → synth low) | synthesis model chunk-selection + prompt formatting |
| source_recall (retrieval high → synth low) | intent classifier routing / router tool selection |
| All scores low in BOTH modes | retrieval primitive (embed / BM25 / atlas-tier / reranker) |

Where this lives:
- `sovereign-cli/src/bench_cmd/all.rs::Opts.synth` (default false)
- `sovereign-cli/src/eval_cmd/runner.rs::run_bank_synth` — the synth driver
- `sovereign-core/src/runtime.rs::handle_message_stream` — the chat-shared entry point
- Baselines: `sovereign/bench/<group>/baselines/<bench>-synth/latest.json`
