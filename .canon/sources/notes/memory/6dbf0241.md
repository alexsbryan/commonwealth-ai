# Architectural drift is lazily evaluated, not scheduled. drift_posture MCP tool reports fresh/stale/partial/never_run against a fingerprint…

**Architectural drift is lazily evaluated, not scheduled. `drift_posture` MCP tool reports fresh/stale/partial/never_run against a fingerprint sidecar; the brief and pre-push gate read it. The launchd plist was removed.**

`sovereign drift detect` writes a fingerprint sidecar at
`~/.sovereign/drift/.fingerprint` recording SHA-256s of every narrative
doc fed into the report. The `drift_posture` MCP tool re-hashes the
narrative docs and reports one of `fresh | stale | partial | never_run`.

Why: The earlier plan called for a weekly launchd cron, but cron is
the wrong interface — it invalidates on a clock tick rather than a
meaningful change, and it doesn't compose with the existing
freshness-gate pattern (`lint_status`, `test_status`). Lazy evaluation
fits the same mental model.

How to apply:

- During active editing or session start, call `drift_posture` to learn
  whether the cached drift digest is current. Cheap — two file reads
  plus a couple of SHA-256 hashes on small markdown files.
- When status is `stale` or `never_run`, surface "run `sovereign drift
  detect`" rather than auto-firing — the LLM cost is ~25-30 min per
  narrative, the human should be in the loop.
- The session-start brief renders this as a "Drift posture" section
  between Working set and Principles (skipped when fresh + zero
  Act-on findings).
- The pre-push hook should require fresh `drift_posture` when the push
  includes commits that touch `SYSTEM_OVERVIEW.md` or
  `ARCH_PRINCIPLES.md`.
- mtime is not the freshness signal — `git checkout` and `touch`
  both flip mtime without changing content. SHA-256 is the honest test.

Wired at:
- `sovereign-tools/src/code/drift_posture.rs` — tool + `compute_posture` +
  `write_fingerprint`.
- `sovereign-cli/src/drift_cmd_orchestrator.rs:430+` — writes the
  fingerprint after a successful run.
- `sovereign-tools/src/code/brief.rs::render_drift_posture` — the
  brief's new section.

Landed 2026-05-11. The previously-drafted launchd plist
`sovereign/contrib/launchd/com.commonwealth.drift.plist` was deleted in
the same change.
