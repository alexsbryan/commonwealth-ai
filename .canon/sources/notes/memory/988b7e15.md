# SOVEREIGN_PROMPT_DIR overlay lets prompt MD edits land without rebuilding sovereign-cli

SOVEREIGN_PROMPT_DIR overlay lets prompt MD edits land without rebuilding sovereign-cli

Prompt MD files used to be baked at compile time via `include_str!`, so every prompt-tuning iteration forced a `sovereign-cli` rebuild (~minutes). After 2026-05-15 (Move 2 phase A), pipelines read prompts through `corpus_engine::enrichment::pipeline::prompts::load_or_baked`, which consults `$SOVEREIGN_PROMPT_DIR` first and falls back to the compile-time-baked copy.

Why: prompt iteration was the dominant cost in the bench-tuning loop. Each MD edit triggered a release build of `sovereign-cli` to bake the change into the binary. The hot-reload overlay collapses that to "edit MD → re-run".

How to apply:

```bash
export SOVEREIGN_PROMPT_DIR=~/prompt-overlays
# one-time seed the overlay tree with the current baselines you want to tune:
mkdir -p $SOVEREIGN_PROMPT_DIR/literary_atlas
cp corpus-engine/src/enrichment/pipeline/pipelines/literary_atlas_prompts/phase1_system.md \
   $SOVEREIGN_PROMPT_DIR/literary_atlas/

# iterate
$EDITOR $SOVEREIGN_PROMPT_DIR/literary_atlas/phase1_system.md
sovereign enrich build <corpus>            # overlay loaded on first read
sovereign bench all --filter <bench>       # measure
```

Overlay paths use the convention `<pipeline-stem>/<filename>` — e.g. `literary_atlas/phase1_system.md`, `philosophy_atlas/phase3_question_naming.md`. The `_prompts` segment from the in-tree path is dropped.

Cost: per-process one-time string leak for each overlay-loaded prompt (~10 KB each, ~40 prompts max → ~400 KB ceiling). Acceptable — these are tuning iterations, not long-running services.

Implementation lives at: `corpus-engine/src/enrichment/pipeline/prompts.rs` (resolver + 5 unit tests covering env-unset / env-empty / overlay-missing / overlay-present / overlay-is-dir).

When the env var is unset, behaviour is bit-identical to the pre-refactor compile-time-baked version. Verified 2026-05-15 against obsidian bench (5/5 axes unchanged).
