Microsoft’s Recall feature became a privacy scandal in 2024 because, despite claims that data was encrypted, security researchers demonstrated that the screenshots it captured every few seconds were stored unencrypted (in plaintext) within a local SQLite database [Source: ev-1]. This allowed any process running as the user to access sensitive information, including passwords and private messages, which were captured by default when the feature launched on May 20, 2024 [Source: ev-1]. The discrepancy between Microsoft's "encrypted" claims and the actual storage method led to investigations by regulators such as the Irish Data Protection Commission, the UK Information Commissioner’s Office, and the Washington State Attorney General [Source: ev-1].

In response to these security failures and privacy concerns, Microsoft delayed the release in June 2024 and fundamentally changed how the feature works [Source: ev-1]. The relaunched version is now opt-in (default OFF) rather than enabled automatically [Source: ev-1]. Additionally, accessing the timeline now requires Windows Hello authentication and presence detection, while incognito and DRM content are explicitly excluded from capture [Source: ev-1]. This revised, more secure version of Recall reached general availability on Copilot+ PCs in 2025 [Source: ev-1].
