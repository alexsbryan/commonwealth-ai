OpenAI released o3 and o4-mini on April 16, 2025 [Source: ev-1]. The primary strategic reason for this release was to defend the reasoning-model frontier against competitive pressures from DeepSeek’s R1 cost shock and Anthropic's agentic-coding push, particularly while GPT-5 had not yet shipped [Source: ev-1].

The launch signaled a specific direction for future frontier reasoning models by reframing capability as "tool-using reasoning at commodity prices" [Source: ev-1]. This shift is evidenced by several key technical and commercial features introduced in these models:
*   **Native Integration:** Vision and native tool use (such as web search and code interpreter) were built directly into the model rather than being bolted on afterward [Source: ev-1].
*   **Dynamic Compute:** The models utilized a technique called "budget forcing," which applies a fixed maximum thought budget with task-adaptive dynamic compute, allowing harder questions to trigger longer thinking processes [Source: ev-1].
*   **Privacy Policy:** OpenAI implemented its first private chain-of-thought policy, ensuring that reasoning tokens are not exposed to API callers [Source: ev-1].
*   **Performance and Pricing:** o3 achieved approximately 87.5% accuracy on ARC-AGI-1 at high compute levels, meeting or exceeding the ~85% human baseline as the first model to do so [Source: ev-1]. Concurrently, pricing was set competitively, with o3 costing $10 per million input tokens and $40 per million output tokens, while o4-mini cost $1.10 per million input tokens and 4.40 dollars per million output tokens [Source: ev-1].
