Microsoft's Recall feature became a privacy scandal in 2024 because, despite claims that data was encrypted, security researchers demonstrated that screenshots were stored unencrypted (in plaintext) within a local SQLite database [Source: ev-1]. This vulnerability meant that sensitive information visible on the screen, such as passwords and private messages, was captured by default and could be accessed by any process running under the user account [Source: ev-1]. The feature’s design—a default-on "photographic memory" recording everything displayed—collided with privacy expectations regarding local data storage and handling of health data or other sensitive content [Source: ev-1].

In response to these findings and investigations by authorities like the Irish Data Protection Commission, UK Information Commissioner's Office, and Washington State Attorney General Bob Ferguson, Microsoft changed the feature significantly [Source: ev-1]. Initially delayed in June 2024, Recall was relaunched as an opt-in feature that is off by default [Source: ev-1]. To access the timeline, users are now required to use Windows Hello authentication and presence detection, while incognito mode and DRM-protected content are explicitly excluded from capture [Source: ev-1]. The revised version of this opt-in feature reached general availability on Copilot+ PCs in 2025 [Source: ev-1].
