OpenAI released o3 and o4-mini on April 16, 2025 [Source: ev-1]. The launch signaled a strategic shift in the direction of frontier reasoning models toward integrating vision directly into the model architecture rather than bolting it on, alongside native tool use (such as web search and code interpreter) trained intrinsically into the system [Source: ev-1].

The release also highlighted OpenAI’s adoption of "budget forcing," a technique utilizing a fixed maximum thought budget with task-adaptive dynamic compute to allow harder questions to require longer thinking times [Source: ev-1]. Furthermore, the launch marked OpenAI's first private chain-of-thought policy, where reasoning tokens are not exposed to API callers [Source: ev-1]. By making o3 available via API from day one while keeping it out of the ChatGPT app at launch, OpenAI emphasized an API-first approach for developers [Source: ev-1].

Economically and competitively, the launch was designed to defend the reasoning-model frontier against DeepSeek's R1 cost shock and Anthropic’s agentic-coding push in a landscape where GPT-5 had not yet shipped [Source: ev-1]. This strategy reframed frontier capability as tool-using reasoning offered at commodity prices. The pricing structure reflected this accessibility, with o4-mini priced at $1.10 per million input tokens and $4.40 per million output tokens, while o3 was priced higher at $10 per million input tokens and 40 dollars per million output tokens [Source: ev-1].

The release also demonstrated significant performance gains; o3 set a record on the ARC-AGI benchmark by achieving approximately 87.5% accuracy on ARC-AGI-1 at high compute levels [Source: ev-1]. This result placed it at or above the ~85% human baseline, making it the first model to reach this threshold [Source: ev-1].
