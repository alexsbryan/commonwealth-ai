OpenAI released o3 and o4-mini on April 16, 2025 [Source: ev-1]. The launch signaled a strategic direction for frontier reasoning models characterized by the integration of vision directly into the model architecture rather than adding it as an external component [Source: ev-1]. Additionally, these models featured native tool use capabilities—specifically web search and code interpreter—that were trained into the model itself [Source: ev-1].

The release also indicated a shift in technical methodology through "budget forcing," which utilizes a fixed maximum thought budget with task-adaptive dynamic compute to allow harder questions to require longer thinking times [Source: ev-1]. Furthermore, OpenAI introduced its first private chain-of-thought policy, ensuring that reasoning tokens are not exposed to API callers [Source: ev-1].

Commercially, the launch signaled a move toward making frontier capability available at commodity prices while defending against competitors like DeepSeek and Anthropic [Source: ev-1]. This was supported by aggressive pricing structures where o3 cost $10 per million input tokens and $40 per million output tokens, while o4-mini cost $1.10 per million input tokens and 4.40 dollars per million output tokens [Source: ev-1]. The models also demonstrated significant performance improvements, with o3 setting a record on the ARC-AGI benchmark by achieving approximately 87.5% accuracy on ARC-AGI-1 at high compute levels, surpassing or matching the ~85% human baseline as the first model to do so [Source: ev-1].
