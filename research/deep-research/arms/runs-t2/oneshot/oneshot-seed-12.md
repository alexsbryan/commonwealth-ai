Microsoft’s Recall feature became a privacy scandal in 2024 because it was initially designed as an AI "memory" tool that took screenshots of the user's screen every few seconds and stored them locally [Source: ev-1]. Although Microsoft claimed these files were encrypted, security researchers demonstrated that the screenshots—including sensitive content such as passwords—were actually stored unencrypted (in plaintext) within a local SQLite database [Source: ev-1]. This made the data accessible to any process running under the same user account, contradicting Microsoft's security assurances and violating privacy expectations for local data [Source: ev-1].

In response to this crisis, which involved inquiries from the Irish Data Protection Commission, the UK Information Commissioner's Office, and an investigation by the Washington State Attorney General, Microsoft delayed the feature in June 2024 and subsequently reversed its default settings [Source: ev-1]. The relaunched version of Recall is now opt-in (default OFF), requires Windows Hello authentication and presence detection to access the timeline, and excludes incognito or DRM-protected content [Source: ev-1]. This revised, opt-in version reached general availability on Copilot+ PCs in 2025 [Source: ev-1].
