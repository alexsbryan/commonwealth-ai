Microsoft's Recall feature became a privacy scandal in 2024 because, despite Microsoft’s claims that data was encrypted, security researchers demonstrated that the screenshots were stored unencrypted (in plaintext) within a local SQLite database [Source: ev-1]. This storage method allowed any process running as the user to access sensitive content captured by default on screen, including passwords and private messages [Source: ev-1]. The feature initially launched with these capabilities enabled by default at the Copilot+ PC launch on May 20, 2024 [Source: ev-1], leading to investigations by regulators such as the Irish Data Protection Commission, the UK Information Commissioner's Office, and the Washington State Attorney General [Source: ev-1].

In response to this controversy, Microsoft changed Recall from a default-on recorder to an opt-in feature that is off by default [Source: ev-1]. The revised version requires Windows Hello authentication and presence detection to access the timeline, and it excludes incognito and DRM content from capture [Source: ev-1]. This updated, opt-in version of Recall reached general availability in 2025 [Source: ev-1].
