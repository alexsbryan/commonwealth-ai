OpenAI released o3 and o4-mini on April 16, 2025 [Source: ev-1]. The primary reason for this release was to defend the frontier of reasoning models against competitive pressures from DeepSeek’s R1 cost shock and Anthropic’s agentic-coding push, particularly while GPT-5 had not yet shipped [Source: ev-1].

The launch signaled a specific direction for future frontier reasoning models by reframing capability as "tool-using reasoning at commodity prices" [Source: ev-1]. This shift is evidenced by several key technical and strategic features introduced in these models:
*   **Native Vision:** They were the first OpenAI reasoning models with vision built directly into the model itself rather than being bolted on [Source: ev-1].
*   **Integrated Tool Use:** The models featured native tool use (such as web search and code interpreter) that was trained into the architecture, supporting the agentic focus of the new frontier definition [Source: ev-1].
*   **Budget Forcing Technique:** The launch highlighted a technique involving a fixed maximum thought budget combined with task-adaptive dynamic compute, allowing harder questions to require longer thinking times [Source: ev-1].
*   **Privacy Standards:** It marked OpenAI’s implementation of its first private chain-of-thought policy, ensuring reasoning tokens were not exposed to API callers [Source: ev-1].

Additionally, the release demonstrated competitive performance and pricing strategies. o3 set a record on the ARC-AGI benchmark, achieving approximately 87.5% on ARC-AGI-1 at high compute, which met or exceeded the ~85% human baseline as the first model to do so [Source: ev-1]. Pricing was structured with o3 at $10 per million input tokens and $40 per million output tokens, while o4-mini was priced lower at $1.10 per million input tokens and 4.40 dollars per million output tokens [Source: ev-1]. The launch also signaled an API-first approach for developers, as both models were available via API from day one, though only o4-mini was initially included in the ChatGPT app [Source: ev-1].
