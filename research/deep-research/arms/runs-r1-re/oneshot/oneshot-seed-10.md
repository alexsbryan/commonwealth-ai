OpenAI released GPT-5 on August 7, 2025 [Source: ev-1] to consolidate its strategy around a single unified model and shift the competitive focus from benchmark demonstrations to "default agency"—models that act rather than just answer [Source: ev-1]. This release marked a deliberate strategic pivot toward aggressive distribution by making frontier capabilities available immediately to free users [Source: ev-1].

This launch fundamentally changed how OpenAI sells its models in several key ways:
*   **Pricing Model:** It implemented a "give-away-the-frontier" pricing structure where GPT-5 is free for basic users, with paid tiers at $20/month for Plus (offering unlimited access) and $200/month for Pro [Source: ev-1]. API costs were set at $1.25 per million input tokens and $10 per million output tokens for the standard model, while the mini version cost $0.25 and $2 respectively [Source: ev-1]. This represented a significant price collapse compared to previous offerings [Source: ev-1].
*   **Product Consolidation:** OpenAI retired its separate "o-series" reasoning products—specifically o3, o4-mini, o3-mini, and o3-pro—and folded their capabilities into GPT-5's internal "reasoning modes" [Source: ev-1]. This ended the distinction between reasoning and non-reasoning models, removing the need for users to select different model types as GPT-5 was pitched as simply "a model that thinks" [Source: ev-1].
*   **Feature Integration:** The release bundled advanced features directly into a single interface, including native image generation (eliminating the need for a separate image model), integrated deep research, file upload, web search, and a 5-million-token context window [Source: ev-1].

Despite these changes in sales strategy and product structure, the performance remained competitive, with GPT-5 scoring approximately 78.6% on SWE-bench Verified [Source: ev-1].
