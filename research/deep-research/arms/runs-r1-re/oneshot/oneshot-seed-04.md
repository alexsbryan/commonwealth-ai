OpenAI released o3 and o4-mini on April 16, 2025 [Source: ev-1]. The launch signaled that the direction of frontier reasoning models is shifting toward integrating vision directly into the model architecture rather than bolting it on, as well as incorporating native tool use (such as web search and code interpreter) trained directly into the model [Source: ev-1].

Strategically, with GPT-5 not yet shipping, OpenAI used this release to defend its position at the frontier against DeepSeek's R1 cost shock and Anthropic’s agentic-coding push [Source: ev-1]. This move reframed frontier capability as "tool-using reasoning at commodity prices" [Source: ev-1]. To support this positioning, o3 was priced at $10 per million input tokens and $40 per million output tokens, while o4-mini was priced significantly lower at $1.10 per million input tokens and 4.40 dollars per million output tokens [Source: ev-1].

The launch also highlighted a shift in how reasoning is managed and disclosed. OpenAI employed "budget forcing," which uses a fixed maximum thought budget with task-adaptive dynamic compute so that harder questions require longer thinking times [Source: ev-1]. Additionally, the release marked OpenAI's first private chain-of-thought policy, meaning reasoning tokens are not exposed to API callers [Source: ev-1]. The capability of these models was demonstrated by o3 setting a record on the ARC-AGI benchmark, achieving approximately 87.5% on ARC-AGI-1 at high compute, which met or exceeded the ~85% human baseline for the first time [Source: ev-1].
