Microsoft's Recall feature became a privacy scandal in 2024 because, despite claims of encryption, security researchers demonstrated that the screenshots it captured every few seconds were stored unencrypted (in plaintext) within a local SQLite database [Source: ev-1]. This vulnerability meant that sensitive data visible on screen, such as passwords and private messages, was accessible to any process running under the user account by default [Source: ev-1]. The incident sparked significant regulatory scrutiny, with investigations opened by the Washington State Attorney General and questions raised by both the Irish Data Protection Commission and the UK Information Commissioner's Office [Source: ev-1].

In response to these security failures and privacy concerns, Microsoft changed how the feature operated. Initially delayed in June 2024, Recall was relaunched with an opt-in model where it is turned off by default rather than being a pre-installed active recorder [Source: ev-1]. To further protect user data, accessing the timeline now requires Windows Hello authentication and presence detection, while incognito mode and DRM content are explicitly excluded from capture [Source: ev-1]. The revised version of this "photographic memory" tool reached general availability on Copilot+ PCs in 2025 [Source: ev-1].
