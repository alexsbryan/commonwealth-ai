Microsoft's Recall feature became a privacy scandal in 2024 because, despite claims that data was encrypted, security researchers demonstrated that the screenshots were stored unencrypted (in plaintext) within a local SQLite database [Source: ev-1]. This storage method allowed any process running as the user to access sensitive content captured by default on screen, such as passwords and private messages [Source: ev-1]. The discrepancy between Microsoft’s security assurances and the actual vulnerability of this "photographic memory" tool triggered investigations from regulatory bodies like the Irish Data Protection Commission, the UK Information Commissioner's Office, and the Washington State Attorney General [Source: ev-1].

To address these concerns, Microsoft initially delayed the feature in June 2024 before reversing its design approach [Source: ev-1]. The relaunched version changed Recall from a default-on recorder to an opt-in feature that is off by default [Source: ev-1]. Additionally, accessing the timeline now requires Windows Hello authentication and presence detection, while incognito and DRM content are explicitly excluded from capture [Source: ev-1]. This revised, privacy-focused version of Recall reached general availability on Copilot+ PCs in 2025 [Source: ev-1].
