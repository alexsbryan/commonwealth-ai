OpenAI released o3 and o4-mini on April 16, 2025 [Source: ev-1]. The launch signaled a strategic shift in frontier reasoning models toward integrating vision directly into the model architecture rather than bolting it on, while simultaneously embedding native tool use (such as web search and code interpreter) via training [Source: ev-1]. This approach utilized "budget forcing," which applies task-adaptive dynamic compute so that harder questions receive longer thinking times within a fixed maximum thought budget [Source: ev-1].

The release also marked OpenAI’s first private chain-of-thought policy, where reasoning tokens are not exposed to API callers [Source: ev-1]. By launching these models with an API-first strategy—making o3 available to developers from day one but initially excluding it from the ChatGPT app—OpenAI aimed to defend its position on the frontier against competitors like DeepSeek and Anthropic [Source: ev-1]. The launch reframed frontier capability as tool-using reasoning offered at commodity prices, highlighted by aggressive pricing for o4-mini ($1.10 input / $4.40 output per million tokens) compared to o3 ($10 input / $40 output per million tokens), while maintaining high performance such as achieving approximately 87.5% on ARC-AGI-1 [Source: ev-1].
