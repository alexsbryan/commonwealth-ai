OpenAI released o3 and o4-mini on April 16, 2025 [Source: ev-1]. The launch signaled that the direction of frontier reasoning models is shifting toward "tool-using reasoning at commodity prices" [Source: ev-1]. Specifically, OpenAI reframed frontier capability by introducing native tool use (such as web search and code interpreter) directly into the model architecture rather than bolting it on [Source: ev-1]. This strategic move was intended to defend the reasoning-model frontier against DeepSeek's R1 cost shock and Anthropic’s agentic-coding push while GPT-5 had not yet shipped [Source: ev-1].

The release highlighted a new approach using "budget forcing," which employs a fixed maximum thought budget with task-adaptive dynamic compute so that harder questions require longer thinking times [Source: ev-1]. Additionally, o3 demonstrated significant performance gains, setting a record of about 87.5% on ARC-AGI-1 at high compute, reaching or exceeding the ~85% human baseline as the first model to do so [Source: ev-1]. The launch also marked OpenAI's first private chain-of-thought policy, where reasoning tokens are not exposed to API callers [Source: ev-1]. Pricing for these models was set at $10 / $40 per million input/output tokens for o3 and $1.10 / $4.40 for o4-mini [Source: ev-1].
