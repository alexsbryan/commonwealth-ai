Microsoft’s Recall feature became a privacy scandal in 2024 because it was initially designed to run by default, continuously screenshotting the user's screen every few seconds and storing this data locally [Source: ev-1]. Security researchers, notably Kevin Beaumont, demonstrated that despite Microsoft’s claims of encryption, these screenshots were stored unencrypted (in plaintext) within a local SQLite database [Source: ev-1]. This storage method made sensitive information visible on screen—such as passwords, health data, and private messages—accessible to any process running with user privileges [Source: ev-1]. The collision between the feature’s value proposition of "photographic memory" and fundamental privacy expectations led regulatory bodies, including the Irish Data Protection Commission, the UK Information Commissioner's Office, and the Washington State Attorney General, to raise questions or open investigations [Source: ev-1].

To address these concerns, Microsoft delayed the launch in June 2024 and subsequently reversed its default settings [Source: ev-1]. The relaunched version is now opt-in (default OFF) rather than enabled by default [Source: ev-1]. Additionally, accessing the timeline requires Windows Hello authentication and presence detection, while incognito mode and DRM content are explicitly excluded from capture [Source: ev-1]. Although this revised, opt-in Recall reached general availability on Copilot+ PCs in 2025, the initial controversy permanently shaped privacy discussions surrounding AI-powered personal computers [Source: ev-1].
